## 本地运行

后端使用项目已有的 Python 环境和 `.env`，从 `rag_app/` 启动：

```bash
python -m uvicorn api_server:app --host 0.0.0.0 --port 8000
```

网页生产构建已经生成于 `react/dist/`，后端会直接提供网页。浏览器打开 `http://127.0.0.1:8000`。若独立开发网页，从 `react/` 执行 `npm run dev`。

微信开发者工具导入 `rag_app/weapp/`，核对自己的 AppID。登录页“后端连接设置”中：开发工具使用 `http://127.0.0.1:8000`；真机使用电脑的实际局域网 IP，例如 `http://192.168.1.100:8000`。本地开发需按 [部署说明](weapp/DEPLOY.md) 配置域名校验与网络可达性。

设备中心会展示已有的模拟记录。新安装的空设备库可以显式填入模拟记录：

```bash
python equipment_cli.py --db data/equipment.db demo
```

该命令只允许向空库填入演示记录，不会覆盖已有业务数据；升级和启动不会自动重复填入。演示按钮使用规则查询，无需等待在线模型。普通自然语言问题可按现有模型配置使用 Text-to-SQL。
