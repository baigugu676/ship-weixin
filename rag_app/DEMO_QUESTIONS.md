## 四、图片识别演示流程（已验收）

1. 上传一张设备/报警面板照片（建议提前准备 2~3 张：报警面板、铭牌、渗漏部位）
2. 补充说明填设备名（如"主机控制面板"）→ 开始识别（约 10~30 秒）
3. 描述出来后**手动改一两处再点诊断**（演示"人机协同"亮点）
4. 点开始诊断 → 卡片自动折叠不挡回答 → 流式出结果带引用

## 五、海上天气演示流程（已验收）

1. 右侧栏"海上天气"卡片 → 详请 → 搜索"舟山"添加 → 看 5 天预报（风/浪高/海温）
2. 切"历史查询"页签 → 选去年某月 → 逐日回看（说明：浪高仅回看 92 天，气象可查 1940 年起）
3. 点"点击定位"获取当前位置（localhost 下可用）

## 六、演示注意事项

- **后端启动后等 1~2 分钟**（后台自动预热重排序模型，日志见 "Model loaded successfully"）再开始问答，首题即快
- 在线模式单题 60~180 秒（ModelScope 免费档），期间有"检索中→图谱→生成"进度提示，不会截断；如需快节奏，可在设置里开**离线模式**（抽取式回答，2~4 秒出全结果，照样带引用和图谱）
- 本地 Neo4j 依赖 Docker Desktop；若 KG 无结果且明显变慢，先检查 Docker Desktop 是否在运行、`neo4j-rag` 容器是否启动
- 云端演示备用：预览地址见 `.cloudstudio-access/deploy-state.md`，工作区停止时先去 cloudstudio.net 启动
